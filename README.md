# Parking Availability Prediction

## Objective
To predict whether parking is Available or Occupied using
a Logistic Regression machine learning model.

## Algorithm
Logistic Regression

## Dataset
parking_birmingham.csv

The included CSV is an illustrative sample dataset, not the
official Birmingham parking dataset.

## Features
- Day
- Time
- Capacity
- Occupied Spaces

## Target
Status: Available or Occupied

## How to Run
1. Install Python.
2. Install the required libraries:
   pip install pandas scikit-learn
3. Keep the Python program and CSV in the same folder.
4. Run:
   python parking_availability_prediction.py

## Output
The program displays the dataset, model accuracy,
classification report, and predicted parking status.
